## Core Pencil2D Features

- **Frames You Draw:** Each frame is a picture you make. Playback shows them in order.
- **A Project File:** Save the animation as a project so you can add frames later. An export is a movie or an image sequence for other people to watch.
- **A Short First Loop:** A few frames that repeat teach the timeline better than a long unfinished scene.
- **Layers If You Need Them:** A separate layer can hold a background you do not want to redraw every frame.

---

## About Pencil2D

Pencil2D is a simple animation program for drawings you create. A short loop, a title card you animate, or a class exercise you are assigned can live in one project. It does not include a library of commercial cartoons, and tracing a film you do not have rights to is not a student project just because the tool is simple.

Save the project often. The export is what you show. If you only export and then lose the project, the next frame is much harder to match. Keep the project and the export in a folder you can find. A large canvas and a high frame rate make a heavy file before the idea is proven. Start small.

Play the loop inside Pencil2D, then open the export in an ordinary player. A timing that feels right in the editor can still stutter in the file you send.

## Getting Started with Pencil2D

Prerequisites: A folder for the project and a short idea, such as a two-second loop.

1. **New Project:** Set a modest size and save it immediately.
2. **Draw a Few Frames:** Play them. Add a frame only when the motion is clear.
3. **Save Again:** The project file is the one you will reopen.
4. **Export and Watch:** Open the movie outside Pencil2D before you call it finished.
